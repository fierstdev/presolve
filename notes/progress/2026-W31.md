## Package usage classification amendment

Authored `docs/v2/package-usage-classification-contract.md` to remove package-
wide decorator admission as the long-term third-party model. External package
diagnostic depth is now classified per authority-proven use site: erased or
Vite-owned inputs create no Presolve runtime semantic; discarded terminal
client calls are bounded capabilities; values entering State, Computed,
rendering, Forms, Context, serialization, or resume require a closed semantic
contract; and framework/server integrations retain dedicated products.

The first executable slice is deliberately narrow and testable: a synchronous
decorator-free V2 Action whose complete body calls one named import with no
arguments and discards its result. TypeScript authority must prove the exact
export, Vite must publish a digest-inventoried callable registry, and real-
browser evidence must prove execution, compatible resume, deterministic
publication, and failure diagnostics. This amendment does not synthesize
`@opaque`, inspect package source, or claim compatibility with packages built
for another host runtime.
