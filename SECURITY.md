# Security policy

Please do not file public issues for a suspected vulnerability. Report it
privately to the repository maintainers through the security contact configured
by the hosting platform. Include affected revision, reproduction steps, impact,
and a safe proof when possible.

This repository has no hosted service, production deployment, or response-time
commitment. Reports are assessed against the supported repository surfaces; no
security advisory, fix, disclosure date, or release is promised by this policy.
