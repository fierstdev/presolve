# Representative applications contract

The representative application corpus is a schema v1 inventory of conventional
projects, not a second compiler fixture grammar. Each project is copied to a
temporary root and built through the zero-configuration ergonomic production
command. The proof requires route-scoped `resume.runtime.json` and a passing
compiler `production-audit.json` for every application.

`counter-resume` exercises stateful resumable publication. `nested-routes`
exercises conventional layouts, default Slot composition, and nested route
publication. Cold/resume browser behavior remains covered by the canonical
runtime-browser corpus; compiler-selected HMR transport remains covered by the
Vite adapter proof. This corpus joins those product gates to complete project
builds without duplicating either runtime or HMR semantics.
