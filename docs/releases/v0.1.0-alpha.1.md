# Presolve 0.1.0-alpha.1

This is the first packaged developer-preview release of the current Presolve architecture.

Presolve is pre-stable. This release is intended for evaluation, architectural feedback, and portability experiments rather than production use.

## What this release proves

Presolve separates an application's immutable release identity from the environment that supplies its execution requirements.

The current workflow is:

```text
presolve.toml
    ↓
presolve build
    ↓
application.presolved
    +
presolve.env.toml
    ↓
presolve check / presolve plan
    ↓
compatibility result + inspectable DeploymentPlan
```

A `.presolved` release does not contain environment-specific provider selections, credentials, endpoints, registry locations, or placement decisions.

## CLI surface

The developer-preview CLI includes:

```text
presolve build
presolve inspect [RELEASE]
presolve check
presolve plan
presolve dev
presolve env init
presolve env check
presolve env show
presolve env provider add
presolve env provider list
presolve env provider remove
```

`inspect`, `check`, and `plan` expose versioned machine-readable JSON where applicable.

## Workload and authoring paths

The current release supports the implemented Presolve paths for:

- WebAssembly Component workloads
- immutable OCI container descriptor identity
- Rust Component source builds
- TypeScript Component source builds through the current Jco/ComponentizeJS adapter
- prebuilt Components
- mixed Component/container application releases

The TypeScript SDK exposes provider-neutral KV and object-storage capability APIs. The real TypeScript OCI path is exercised end to end in public CI.

## Providers and portability evidence

Implemented provider paths include:

- in-memory key-value storage
- in-memory object storage
- Cloudflare Workers KV through the node-side realization boundary

Public CI exercises core tests, TypeScript authoring, architecture checkpoints, deterministic release packaging, inspection/planning behavior, provider boundaries, and real Docker OCI execution without requiring cloud credentials.

A separate opt-in checkpoint exists for the live Cloudflare Workers KV proof.

## Native CLI artifacts

The GitHub prerelease publishes native CLI archives and SHA-256 checksum files for:

```text
x86_64-unknown-linux-gnu
aarch64-unknown-linux-gnu
x86_64-apple-darwin
aarch64-apple-darwin
```

Each archive contains:

```text
presolve
LICENSE
```

Verify the downloaded archive against its adjacent `.sha256` file before use.

## Pre-stable boundaries

This release does not establish stable compatibility guarantees for the CLI, Application Contract, Environment Specification, capability contracts, `.presolved` bundle format, TypeScript SDK, or deployment lifecycle.

It also does not provide a Presolve control plane, scheduler, service mesh, registry, Homebrew package, installer script, Windows binary, Apple notarization, or general production deployment system.

The immediate post-release work remains product proof: demonstrate the exact same `.presolved` release digest across materially different environments/providers, add another real provider with different semantics, and gather external developer feedback before expanding the platform surface.
