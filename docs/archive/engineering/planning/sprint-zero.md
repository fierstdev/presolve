# Sprint Zero

## Goal

Create the minimum project infrastructure needed to learn and develop without losing decisions.

## Work items

1. Initialize repository.
2. Add Rust workspace.
3. Add TypeScript workspace.
4. Add first compiler fixture.
5. Add `ezc explain` command shape.
6. Add ADR/RFC directories.
7. Add issue and PR templates.
8. Add weekly progress log.

## Definition of done

- A new contributor can clone the repo and understand the first slice.
- The CLI shape is visible.
- The first fixture exists.
- There is a documented parser-selection RFC.
- No major architecture is hidden in private notes.
