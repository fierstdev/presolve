# Engineering archive

This archive records EdgeZero-era and pre-public Presolve engineering history.
Its documents may contain obsolete names, proposals, commands, and repository
paths. They are non-normative unless another authoritative document explicitly
incorporates them.

The archive preserves historical planning, accepted spike evidence, and
resource notes without rewriting their original contents. Current repository
boundaries are documented in [`../../repository-layout.md`](../../repository-layout.md).
