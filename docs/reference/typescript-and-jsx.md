# TypeScript and JSX

Presolve 0.2 beta uses the TypeScript 7.0 toolchain generated by
`create-presolve`. The starter uses class fields and compiler intrinsics,
strict checking, NodeNext module resolution, and `jsx: "preserve"`:

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "strict": true,
    "noEmit": true,
    "jsx": "preserve",
    "skipLibCheck": true
  }
}
```

Use the project's installed TypeScript version. Presolve's extension does not
suppress or replace TypeScript diagnostics.

## TSX

TSX appears in `render()` methods. Intrinsic HTML elements, static attributes,
compiler-admitted dynamic attributes, and compiler-admitted event handlers are
available. Use `className` and `htmlFor` for their corresponding HTML
attributes. Keep dynamic expressions simple and typed so the compiler can
lower their meaning.

Pass an action directly for an event when possible:

```tsx
<button onClick={this.save}>Save</button>
```

Use a closure only when it captures an admitted value:

```tsx
<button onClick={() => this.remove(todo.id)}>Remove</button>
```

Arbitrary JSX transforms, arbitrary DOM mutation, and arbitrary TypeScript
control flow are not implied by TSX type acceptance. The compiler reports a
diagnostic when it cannot establish the required semantics.
