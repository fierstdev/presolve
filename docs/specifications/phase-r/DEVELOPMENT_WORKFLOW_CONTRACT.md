# Phase R Development Workflow Contract

`presolve dev` is the normal no-configuration local workflow. From a project
root it performs the same compiler-owned discovery, package-contract
resolution, file-route validation, and application publication as
`presolve build`, but requests the compiler's development publication profile
and serves the exact published release on `127.0.0.1:3000`.

`presolve dev --port <u16>` selects another loopback port. `presolve dev
--once` runs the development publication and exits; it is intended for editor,
CI, and integration use.

The server is an HTTP host for compiler-generated bytes. It does not parse
application source, evaluate components, implement a router, alter artifacts,
or provide a framework runtime. It serves only contained published assets and
returns 404 for missing or traversal paths.

Automatic source watching, incremental republishing, and browser update
transport require their own compiler/session contract and are deliberately not
implied by this initial development host.
