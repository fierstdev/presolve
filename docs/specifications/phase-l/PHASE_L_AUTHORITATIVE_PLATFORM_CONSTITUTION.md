# 1. Purpose

Phase L transitions the project from an internal compiler implementation ("Presolve") into the publicly released compiler platform known as **Presolve**.

Unlike previous phases, Phase L does **not** extend the compiler language.

Instead, it establishes the complete platform architecture surrounding the compiler.

The compiler produced by Phase K is considered semantically complete.

Phase L builds the platform around that compiler.

---

# 2. Constitutional Principle

The compiler shall remain the authoritative source of truth.

Every tool, service, cache, visualization, IDE feature, daemon, documentation artifact, and developer experience feature shall consume immutable compiler products.

Nothing shall independently reinterpret source code.

Compiler products are the API.

# 6. Architectural Philosophy

Presolve is a compiler-first platform.

The runtime is intentionally minimal.

The compiler performs maximum work.

Developer tooling consumes compiler knowledge rather than reconstructing it.

Every platform subsystem shall reinforce this philosophy.
