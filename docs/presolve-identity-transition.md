# Presolve identity transition

Presolve is the public product, compiler, executable, package namespace,
repository destination, and website identity. The canonical command is
`presolve`; the public package scope is `@presolve`; the public repository
destination is `github.com/fierstdev/presolve`; and the website is
`presolve.dev`.

The original L1 public-surface transition is superseded where it conflicts with
the [identity migration contract](presolve-identity-migration-contract.md).
That owner-directed amendment extends the namespace migration through active
compiler/runtime representations and implementation names, without changing
language semantics or identity meaning.

Historical material remains only in `docs/archive/` and `notes/progress/`.
Those directories are non-normative provenance, never active product
authority, and are excluded from the current spelling verifier.
