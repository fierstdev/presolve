# Presolve launch site source

This directory contains versioned L18 launch content only. It is not a deployed
website, a web server, or a runtime package. Deployment remains external to
this repository.

The source routes are [home](content/index.md), [documentation](content/docs.md),
[architecture](content/architecture.md), [examples](content/examples.md),
[benchmark methodology](content/benchmarks.md), [roadmap](content/roadmap.md),
and the [non-functional playground placeholder](content/playground.md).

The L18 verifier validates the declared pages and all repository-local Markdown
links.
