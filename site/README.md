# Historical launch-content prototype

This directory preserves the repository-local content prototype created before
the public alpha release. It is not the source of the official Presolve
website, a web server, or a runtime package. The official site can be built
independently with the published Presolve packages and deployed by its owner.

The source routes are [home](content/index.md), [documentation](content/docs.md),
[architecture](content/architecture.md), [examples](content/examples.md),
[benchmark methodology](content/benchmarks.md), [roadmap](content/roadmap.md),
and the [non-functional playground placeholder](content/playground.md).

The historical L18 verifier continues to validate the declared pages and all
repository-local Markdown links.
