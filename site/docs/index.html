Developer Preview

Clone it and ask Presolve questions.

git clone https://github.com/fierstdev/presolve.git
cd presolve
cargo build -p presolve-cli
export PATH="$PWD/target/debug:$PATH"

presolve env init
presolve inspect
presolve check
presolve plan

The four core commands answer different questions: what does the app require, what immutable release are we distributing, can this environment satisfy it, and what exact provider/workload selections did the resolver make?
