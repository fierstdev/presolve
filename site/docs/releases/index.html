The release does not know where it will run.

A .presolved file is the application package produced by Presolve: application semantics and workload identity without environment-specific provider selection.

Portability starts with a stable thing to move. Presolve packages validated application semantics and immutable workload identity once, then evaluates that release against environments later.

Bundle format

Current .presolved format: 0.2.

orders.presolved
├── manifest.json
└── artifacts/
    ├── api.wasm
    └── worker.wasm

The archive is deterministic tar. Component artifacts are embedded under artifacts/<workload>.wasm. Container workloads record immutable OCI descriptor identity rather than registry location, tags, credentials, or pull URLs.

Proof technique

Presolve verifies both logical identity and exact archive bytes.

+

The first identifies the logical Presolve release. The second proves that the exact file passed through planning and execution did not mutate. Same-release proofs record both before environment selection and verify both afterward.

What is absent

Deployment details are intentionally excluded.

Inside the release
  • application requirements
  • workload identity
  • capability requirements
  • resource/network intent
  • application topology
Outside the release
  • selected environment ID
  • selected provider IDs
  • deployment plan
  • credentials/secrets
  • endpoints, buckets, database paths
  • registry locations and deployment placement
Workload identity

Components and containers participate differently.

Component workload

The .wasm artifact is embedded in the archive. Its digest, size, and media type are recorded in the manifest.

Container workload

The release records the immutable OCI image manifest/index descriptor. Registry hostname, repository, tag, credentials, and pull URL remain outside application identity.

Verification

Decoding revalidates the release.

The bundle decoder verifies supported format, safe paths, duplicate/unexpected entries, topology, artifact shape, embedded artifact presence, OCI descriptor form, artifact sizes/digests, and capability requirement structure. Malformed or adversarial archives are rejected before compatibility checks or execution.

presolve build
presolve inspect dist/orders.presolved

cd path/to/environment
presolve plan /absolute/path/to/dist/orders.presolved

The last command evaluates the already-built release against the environment in the current directory. It does not rebuild the application.
