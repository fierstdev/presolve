Why Presolve

Infrastructure can change without turning your app into a different build.

Presolve separates what your application needs from the specific service that provides it.

01Write needs, not vendor choices

Your application can ask for storage, SQL, queues, and other services without making one provider part of the application itself.

02Check before you ship

Presolve tells you whether an environment can satisfy the application and reports what is missing when it cannot.

03Keep the build unchanged

Move the same packaged application between environments instead of rebuilding it just to switch infrastructure.

The workflow

Four commands. Four useful answers.

You can use Presolve without learning its internal architecture first.

presolve inspectWhat does my application need?
See the application Presolve understands before choosing an environment.
presolve buildWhat am I distributing?
Create the packaged application that can be checked against different environments.
presolve checkCan it run here?
Verify that the current environment can provide everything the application requires.
presolve planWhat will it use?
See the exact runtime and providers Presolve selected before execution.

Available today

This is working software, not a portability mockup.

Presolve is still pre-stable, but the core build, compatibility, planning, provider, and proof paths are implemented and checked in public CI.

01Application builds

Create deterministic .presolved packages from supported authoring paths.

02Compatibility checks

Detect when an environment cannot provide something the application requires.

03Inspectable plans

See the providers and versions selected before runtime objects are created.

04Multiple providers

Current implementations include memory, Redis, Cloudflare KV, S3-compatible storage, SQLite, PostgreSQL, and queues.

05Multiple workload paths

WebAssembly Components and OCI/container workload identity and execution paths are represented.

06Public proofs

KV, object-storage, SQL, and queue checks exercise portability and semantic compatibility.
