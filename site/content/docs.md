# Documentation

The [documentation index](../../docs/README.md) distinguishes current
references, accepted guides, and non-normative archive material. Public command
usage is limited to the [CLI reference](../../docs/cli-reference.md); semantic
inspection uses presolve explain, and reserved commands remain unavailable.

The [frozen contract map](../../docs/frozen-contract-map.md) is the entry point
for language, runtime, production, service, cache, workspace, and editor
boundaries.
