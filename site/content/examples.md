# Examples

The alpha corpus contains exactly the examples defined by the
[examples contract](../../docs/examples-contract.md): Counter,
Components/Context/Slots, Forms, explicit workspace, and production/resume.
Each uses explicit source membership and configuration; none provides a
scaffolding or discovery workflow.

- [Counter configuration](../../examples/counter/presolve.json)
- [Components/Context/Slots configuration](../../examples/components-context-slots/presolve.json)
- [Forms configuration](../../examples/forms/presolve.json)
- [Explicit workspace configuration](../../examples/explicit-workspace/presolve.json)
- [Production/resume configuration](../../examples/production-resume/presolve.json)
