# Presolve

Presolve is a compiler platform with explicit compiler-owned products and
bounded public workflows. This launch content describes only the capabilities
and limitations established by the linked repository contracts.

Start with [documentation](docs.md), review the [architecture](architecture.md),
run the bounded [examples](examples.md), understand [benchmark methodology](benchmarks.md),
or read the active [roadmap](roadmap.md). The public repository is
[github.com/fierstdev/presolve](https://github.com/fierstdev/presolve).

The [playground](playground.md) is intentionally non-functional; it does not
compile, upload, store, or execute source.
