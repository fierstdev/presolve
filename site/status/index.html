Next

Broaden queue substitution and semantic precision.

The next queue milestone is a materially different network/managed provider so the exact same queue release can be exercised across providers, as KV, objects, and SQL already are.

Real provider differences are also building evidence for richer typed semantic properties such as limits, retention, lease ranges, and other values that do not fit boolean feature flags.
